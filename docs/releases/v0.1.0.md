# Kavara Brain for Claude v0.1.0

**A privacy-first, self-improving second brain for Claude.** Claude compiles your raw notes into a linked Markdown wiki you read in Obsidian, answers questions from it with citations, files new insights back in, and keeps it healthy. It follows Andrej Karpathy's LLM knowledge-base workflow.

## Install

**Claude Code**
```
/plugin marketplace add danju4rizzl/second-brain
/plugin install kavara-brain@kavara-brain
```
Then open a folder and run `/brain-install`.

**Claude desktop app:** download **`kavara-brain.plugin`** below and install it.

**Other AI tools** (Cursor, Codex, Antigravity, Grok Build): use the [engine](https://github.com/danju4rizzl/second-brain) directly.

Requirements: Node.js 18+ and git. Obsidian recommended.

## What's inside

- **9 modes / slash commands:** `/brain-install` · `/brain-compile` · `/brain-import` · `/brain-ask` · `/brain-file` · `/brain-check` · `/brain-research` · `/brain-publish` · `/brain-weekly`
- **brain-auditor agent:** an independent reviewer, so the AI that wrote the wiki isn't the one grading it
- **Guard hooks (Claude Code):**
  - 🔒 `raw/` is append-only: sources are evidence and can't be edited
  - 🔑 blocks passwords, API keys, tokens and logins from being written into the wiki
  - 🚫 blocks committing or pushing private notes or secrets, including private files in older commits
  - 🔗 rebuilds the index after every wiki edit and reports broken links immediately
  - 📝 reminds Claude to log its changes; shows vault status when a session starts
- Built on **Kavara Brain Engine 1.0.0**, bundled.

## Privacy

Your vault (`raw/`, `wiki/`, `agents.md`) stays on your machine. The vault's `.gitignore` is an allowlist, and the git guard blocks private files even if someone forces them. Credentials found in imports are reported to you, never copied.

## Known limitations

- Hook support in the Claude desktop app may be partial; the same rules are also enforced through the skill instructions.
- Hard guards for non-Claude tools arrive with **Kavara Brain Guard** (planned).
